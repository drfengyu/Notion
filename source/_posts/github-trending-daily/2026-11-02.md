## 1. [pingdotgg/t3code](https://github.com/pingdotgg/t3code)
- **语言**：TypeScript
- **总 Star**：35,883
- **当日新增**：+1,148/天
- **简介**：Theo（t3.gg）团队的 T3 Code——一个把 AI 编码代理请进极简 GUI 的开源项目，本质是给 `claude` / `codex` 一类 CLI agent 做的调度与可视化前端：任务以会话形式排布，改动、终端输出与文件 diff 都在同一界面里呈现，不必再在多个终端窗口之间来回切。
- **亮点**：它的增速曲线比榜单排名更能说明问题——2026 年 8 月中旬还被人当作「1.77 万 star 的 CLI 调度神器」介绍，两个半月后到了 35,883，一天再加 1,148；同期大量同类项目在做「更强的 agent」，它做的是「agent 已经够多了，谁来给它们一个能看的控制台」。

## 2. [Orkas-AI/Orkas](https://github.com/Orkas-AI/Orkas)
- **语言**：JavaScript
- **总 Star**：6,636
- **当日新增**：+1,044/天
- **简介**：MIT 许可的 local-first 桌面「AI 团队」：一个 Commander 负责把你的目标拆成 to-do 并调度 16 个内置专职 agent，同时可以把 Claude Code、Codex、OpenCode、OpenClaw、Hermes 这些外部 agent 一起纳管，附带项目管理、定时自动化与各类连接器；macOS / Windows 免费客户端，既可用内置模型也可填自己的 key。
- **亮点**：7 月初第三方收录时它还是 2.1k star，到今天是 6,636，三个多月翻三倍且近一日新增占总量的 16%，说明这波热度来自产品成形（把「多 agent 编排」从框架名词变成双击安装的应用）而不是概念炒作；它值得盯住的地方是本地密钥与连接器权限的边界处理，这决定了「本地优先」是真承诺还是标语。

## 3. [lightpanda-io/browser](https://github.com/lightpanda-io/browser)
- **语言**：Zig
- **总 Star**：39,353
- **当日新增**：+929/天
- **简介**：Lightpanda，一款为 AI 与自动化设计的无头浏览器：用 Zig 重写，只为脚本与 agent 服务，省掉传统 Chromium 无头模式为渲染像素付出的内存与启动开销，跑得快、体积小，适合大规模并行抓取、测试和 agent  browsing。
- **亮点**：在 agent 浏览器这条赛道上它是少数把「不用 Chromium」做成架构而非口号的项目，3.9 万 star / 日增 929 也说明痛点真实——无头 Chrome 让每个并发会话吃掉数百 MB，是自动化与评测成本的主要来源；风险在于 Web 兼容性是长期苦役，缺渲染引擎的浏览器要一直追赶真实网页的行为差异。

## 4. [vorssaint/vorssaint-utils](https://github.com/vorssaint/vorssaint-utils)
- **语言**：Swift
- **总 Star**：32,007
- **当日新增**：+501/天
- **简介**：免费开源的 macOS 菜单栏工具集，官方说法是「模块化瑞士军刀」——按需启用各个模块而不是装一个全能 App，涉及录屏、辅助功能等 10 项系统权限全部可选、逐个开关，不用就完全不申请。
- **亮点**：这是 macOS 工具类少见的「增长来自设计取向」案例：不打包大而全，而是把权限与模块拆细，用户加星的动力是「它不像其他菜单栏 App 那样一上来就要 8 个权限」；另外注意仓库归属已从 `vorssaintapp/` 迁到 `vorssaint/`，早期链接与 fork 需要重定向。

## 6. [THU-MAIC/OpenMAIC](https://github.com/THU-MAIC/OpenMAIC)
- **语言**：TypeScript
- **总 Star**：42,253
- **当日新增**：+116/天
- **简介**：清华大学 MAIC 团队开源的多智能体互动课堂 OpenMAIC：一键把任意主题变成一间 AI 教室，多个 agent 分工讲课、提问与讨论，学习者可以插入追问，官方提供可直接体验的在线实例（open.maic.chat）。
- **亮点**：今年 3 月开源时靠「清华 + 一键生成 AI 教室」的话题度冲到 4.2 万 star，如今日增 116 已回落到观察期水位，本次是长尾复榜；它比多数「AI 讲课」 Demo 多做的一步是把多 agent 分工与互动问答做成了可自托管的完整前端，但也正因此，评估它的正确问题不是「像不像上课」，而是内容正确性由谁兜底——这类产品的教学价值仍高度依赖上游模型与题库质量。
