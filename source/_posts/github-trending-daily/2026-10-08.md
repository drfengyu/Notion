## 1. [morluto/rea](https://github.com/morluto/rea)
- **语言**：TypeScript
- **总 Star**：15,548
- **当日新增**：+4,655/天
- **简介**：REA（Reverse Engineer Anything）把逆向工程整合成单一 MCP 服务，让编码 Agent 能沿「应用行为 → 运行时 → 原生二进制」逐层往下查——看到感兴趣的功能，就能把它的实现挖到二进制层面。以 npm 包 `rea-agents` 分发，要求 Node.js 22.19+，内置一套面向调查流程的 MCP 工具目录，并提供中英日韩阿多语 README。
- **亮点**：把过去要靠多个人肉工具切换完成的逆向调查，重新包装成 Agent 可直接调用的 MCP 工具集，是「逆向工程工作流 Agent 化」的典型样本，也解释了它单日四千六百多 star 的涨幅。

## 2. [boykopovar/AnyPS5](https://github.com/boykopovar/AnyPS5)

- **总 Star**：10,747
- **当日新增**：+2,716/天
