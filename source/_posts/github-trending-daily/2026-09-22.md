## 1. [Crosstalk-Solutions/project-nomad](https://github.com/Crosstalk-Solutions/project-nomad)
- **语言**：TypeScript
- **总 Star**：37,892
- **当日新增**：+394/天
- **简介**：离线优先的自助式知识与教育服务器，把维基百科、数千本图书、课程、地图以及可选的本地 AI 一并打包进你自己持有的硬件，全程无需联网、通过浏览器访问。Debian 系（推荐 Ubuntu）一条安装脚本部署完毕，服务跑在 8080 端口，另提供 Docker Compose 模板与 Windows/WSL2 安装路径。
- **亮点**：思路是「把互联网最有用的部分预先缓存到一台机器上」，面向断网与应急场景而非又一个自建知识库，对网络受限环境（野外、船上、离线自习室）的部署方是很务实的选择。

## 2. [zhouxiaoka/autoclip](https://github.com/zhouxiaoka/autoclip)
- **语言**：Python
- **总 Star**：8,292
- **当日新增**：+250/天
- **简介**：AI 驱动的二创剪辑工具，分析视频字幕以定位高光、生成话题时间线与片段标题，再自动剪出切片与合集；支持本地视频与 YouTube / B 站链接、可附带 SRT 字幕，导出抖音、小红书、YouTube Shorts、B 站等预设。提供桌面应用、Docker Web 界面和 CLI / MCP 三种用法，模型可接通义千问、OpenAI 兼容接口、Gemini、硅基流动或 Ollama / LM Studio 本地模型。
- **亮点**：少见地把「长视频 → 短视频切片」这条流水线做成了开箱可用的产品（带桌面安装包、八种界面语言），而不是又一份需要自己拼依赖的 notebook 示例。

## 3. [mvt-project/mvt](https://github.com/mvt-project/mvt)
- **语言**：Python
- **总 Star**：13,619
- **当日新增**：+169/天
- **简介**：Mobile Verification Toolkit，移动端取证工具，从 iOS / Android 设备备份中抽取各类工件并与已知监视软件的指标做比对，用来判断设备是否可能被植入监控程序。最初由大赦国际安全实验室（Amnesty International Security Lab）开发，现以独立社区项目维护。
- **亮点**：「手机有没有被装间谍软件」这个问题目前几乎没有别的开源工具能正面回答，它已是调查记者与研究人员核查设备的事实标准之一。

## 4. [akitaonrails/ai-memory](https://github.com/akitaonrails/ai-memory)
- **语言**：Rust
- **总 Star**：7,721
- **当日新增**：+167/天
- **简介**：给 AI 编程智能体做长期记忆的服务端方案。Claude Code、Codex、Cursor、Gemini CLI、OpenCode 等二十多种工具写入同一份共享记忆：在同一个目录里从一个 CLI 换到另一个，下一个智能体能直接拿到「做到哪了、哪些尝试失败了、还有什么悬而未决」的真实交接。记忆存放在你自己运行的服务器上，因此也跨机器、跨团队成员共享。
- **亮点**：直击当前 Agent 工作流最脏的痛点——上下文只活在单个 CLI 里。它把「交接」做成有类型、且恰好被认领一次的协议而非口头约定，比多数 memory 项目更工程化。
