## 1. [anomalyco/opencode](https://github.com/anomalyco/opencode)
- **语言**：TypeScript
- **总 Star**：216,663
- **当日新增**：+1,414/天
- **简介**：开源的 AI 编程 agent，以终端界面为主要形态（npm 上的 `@opencode/cli`），让模型直接在命令行里读写代码、执行命令，而不是绑死在某家 IDE 插件里。
- **亮点**：在 CLI 编程 agent 已被各家第一方产品占满的当下，它今天还能拿到 1,400+ 新增，靠的是「开源可审计、模型可换、代码不出本机」这三点的组合——对需要跑在内网机器或 CI 里、又不愿被单一厂商订阅绑死的团队，这是实际诉求。选型时真正要盯的是权限模型：agent 能执行任意 shell 意味着一次误判就可能直接改坏仓库，接入前先在隔离分支或 worktree 里试、把凭据与生产环境隔开，是最基本的前提。

## 2. [stablyai/orca](https://github.com/stablyai/orca)
- **语言**：TypeScript
- **总 Star**：96,739
- **当日新增**：+1,146/天
- **简介**：面向「同时指挥一队 agent」的编排工具：把 Codex、Claude Code、OpenCode 等编程 agent 并排跑起来，每个各自占一个独立 git worktree，在同一处跟踪与比较结果；覆盖 macOS / Windows / Linux 桌面端，并提供 iOS、Android 伴侣 App，可以在手机上收到完成通知并追加指令，也支持用自己的订阅额度跑任意 agent。
- **亮点**：它切的是单 agent 用满之后的真实瓶颈——限制从「写得快不快」变成了「你能不能同时盯住五路任务并择优合并」。「同一个 prompt 分发给多家 agent、各自 worktree、比稿后取最优」本质上是把 code review 变成了方案竞赛，代价是 token 与等待时间成倍增加，所以更适合解法方向尚不明确的难题，不适合日常增量改动。另一处需要留意的是它将以你的订阅身份执行命令，等于把多个 agent 的凭据和仓库写权限集中交给一个桌面进程；启用远端运行时要先确认哪些内容会离开本机。

## 3. [Comfy-Org/ComfyUI](https://github.com/Comfy-Org/ComfyUI)
- **语言**：Python
- **总 Star**：138,661
- **当日新增**：+154/天
- **简介**：节点式的扩散模型工作流引擎，用图 / 节点界面把模型加载、采样、控制条件、后处理串成可复现的流程，同时提供 API 与本地推理后端，作者称其为最快的本地推理引擎之一。
- **亮点**：作为榜单常客，它的热度来源很稳定——每有新模型放出，最先把生态补齐的往往是这套节点图。对做实际交付的人，值得借鉴的不是它的 UI，而是「工作流即配置」这件事：提示词、采样器、LoRA、分辨率全部落成一张可导出的 JSON，比散落在脚本参数里的配置更容易复现和回归测试。要提醒的是自定义节点属于第三方代码、质量参差；模型大版本升级后最容易踩的是显存峰值与精度（fp8 / bf16）带来的画质漂移，改前先留一组对照图再动手。

## 4. [Kruk2/jasna](https://github.com/Kruk2/jasna)
- **语言**：Python
- **总 Star**：2,440
- **当日新增**：+115/天
- **简介**：跑在本地 GPU 上的视频 / 图像修复工具，先定位画面里的打码（马赛克）区域再重建，其余画面原样不动；提供图形界面和命令行两种用法，免费的 BasicVSR++ 模型走速度路线，更精细的模型需要支持者许可证。硬件要求 NVIDIA GTX 16 / RTX 20 系及以上（AMD RX 7000 / 9000 为实验性支持），路径需纯英文且不支持网络磁盘。
- **亮点**：工程上它有意思的点是「只处理检测到的打码区域」而非整帧超分——既省显存，也避免把不需要重建的部分一起改掉味道，并配了分段预览来人工挑选区域。项目有中/英/日三语 README 和多语言文档，靠卖许可证维持开发，是个典型的独立开发者工具形态。使用边界要说清楚：处理自己有权限、内容合法的材料（例如自采素材的老片修复）没问题；用它还原他人被打码的人脸、证件或隐私画面，既绕过被摄者的同意，在不少法域也触碰法律红线——工具开源并不等于用途免责。

## 5. [mlabonne/llm-course](https://github.com/mlabonne/llm-course)
- **语言**：未标注（以文档与 Notebook 为主）
- **总 Star**：84,067
- **当日新增**：+81/天
- **简介**：一份进入大模型领域的路线课，用 README 组织知识地图、配合 Colab notebook，串起从基础概念到微调、量化、部署的实践路径。
- **亮点**：这类课程仓库的星数涨得慢但长尾极长，价值主要在于它把「该按什么顺序学」固定了下来。更有效的用法不是照着刷完，而是挑与自己手上 GPU 和数据状况相符的章节对照执行——微调、量化、评测这几块的 notebook 稍作替换就是自己项目的脚手架。同时要预期它会过期：模型、库 API 和显存成本半年一变，值得反复读的是讲原理与权衡的部分，具体命令和版本号最好现查最新文档。
