## 1. [tokio-rs/topcoat](https://github.com/tokio-rs/topcoat)
- **语言**：Rust
- **总 Star**：6,853
- **当日新增**：+192/天
- **简介**：tokio 官方组织出品的全栈 Web 框架，主打「模块化、开箱即用」，让开发者只用 Rust 就能写完从服务端渲染到前端交互的整站逻辑。
- **亮点**：它最反常规的设计是**服务端渲染却不需要 API 层**——组件可以是 async 函数并直接查库，省掉传统前后端分离里那套接口定义与序列化样板；而交互又不必付出一次网络往返：模板里的 `$(...)` 表达式是普通且经过类型检查的 Rust，Topcoat 首屏在服务端求值，同时把它翻译成 JavaScript 在浏览器里即时重跑，README 明确强调「没有 wasm 包、没有客户端构建步骤」。仓库挂在 tokio-rs 组织下而非个人项目，采用 MIT 协议、已发布到 crates.io（`topcoat`）并接入 CI 与 Discord。版本节奏上，最新稳定标签是 11-09 的 **v0.12.1**，往前是 10-03 的 v0.11.0、09-13 的 v0.9.0、09-05 的 v0.8.0、08-18 的 v0.6.2——不到三个月从 0.6 走到 0.12 且跳过 0.10，README 顶部也直白写着「早期阶段、实验性，预期会有破坏性变更」，适合先观察和小范围试，不建议直接上生产。

## 2. [we-promise/sure](https://github.com/we-promise/sure)
- **语言**：Ruby
- **总 Star**：12,014
- **当日新增**：+159/天
- **简介**：一款面向所有人的自托管个人财务与资产管理应用，支持流水记录、预算规则、现金流与净资产看板，还带一个能回答储蓄问题的 AI 助手。
- **亮点**：README 开头 IMPORTANT 块说清了它的来历——**它是已停止维护的 Maybe Finance 的社区接管分支**：原团队在 2021–2022 年投入近两年做出全套功能（甚至含连接真人 CFP/CFA 持证理财师的「Ask an Advisor」），在开发上花费近 100 万美元后于 2023 年年中停止开发并开源，随后短暂的官方托管版也没能跑通 B2C 商业模式，于是才有现在这个社区分支维持代码库存活，这也解释了它「for everyone (by everyone)」的口号。发布采用两套并行版本号：`releases.atom` 里最新是 11-10 的 **v2026.11.10-alpha（兼容性对应 v0.7.7-alpha.5）**，此前 11-08、11-03 各发一个按日期命名的 alpha，而真正的功能版本线是 10-24 的 v0.7.6（更早是 10-01 的 v0.7.5-hotfix.2，一个只修 Stripe 删除演示家庭报错的热修复）——日期式 alpha 高频滚动、语义化版本低频兜底，是自托管社区项目很典型的发版分工。
