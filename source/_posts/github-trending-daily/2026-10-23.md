## 1. [php/php-src](https://github.com/php/php-src)
- **语言**：C
- **总 Star**：41,196
- **当日新增**：+287/天
- **简介**：PHP 语言解释器本身的源码仓库，Zend 引擎、核心运行时与标准扩展都在这里开发，代码构成约 69% C、28% PHP，`master` 分支每天仍在推进；官方 releases 同时维护 8.5（当前稳定线）、8.4、8.3、8.2 四条分支。
- **亮点**：这次回榜并不是「老项目又火了」，而是它 2026-10-21 一天内同步发布了 php-8.5.12 / 8.4.27 / 8.3.36 / 8.2.35 四条维护线补丁，运维侧被迫跟进更新才会集中体现在 star 曲线上——对使用方的实际意义是顺手核对线上 PHP 版本还落在哪条分支的支持窗口内，越早的分支（如 8.2）已接近维护末期。

## 2. [Meloong-Git/PCL](https://github.com/Meloong-Git/PCL)
- **语言**：Visual Basic .NET
- **总 Star**：8,717
- **当日新增**：+119/天
- **简介**：国内用户量很大的免费 Minecraft 启动器 Plain Craft Launcher（PCL）的源码仓库，包含 UI 库、动画模块、下载模块与 Minecraft 启动模块等大部分源代码，语言构成约 98% VB.NET + 2% C#；仓库明确说明代码不实时更新，只在每次 PCL 发版时同步一次。
- **亮点**：它提供两个不太常见的参照：一是用 VB.NET 这种「被认为过时」的技术栈把本地工具的体验做到一线，靠作者一人加社区维持；二是协作分层做得干净——功能优先级走 GitHub Discussions 投票、内置帮助文档单独放到 PCL2Help 仓库、正式版从 meloong.com/pcl 下载而非 GitHub Release（该仓库 Releases 为空，且许可证未被 GitHub 识别为标准协议），想借鉴其开源组织方式可以，但真要复用代码前得先确认授权条款而非默认当作 MIT。

## 3. [fastapi/fastapi](https://github.com/fastapi/fastapi)
- **语言**：Python
- **总 Star**：103,779
- **当日新增**：+101/天
- **简介**：高性能、类型提示优先的 Python Web 框架，基于 Starlette 处理请求、Pydantic 做校验，一套类型注解同时给出运行时校验、编辑器补全与自动生成的 OpenAPI 文档，官方定位为「易学、编码快、可用于生产」，当前要求 Python 3.10+。
- **亮点**：它的回榜更像维护强度的信号：2026-10-22 一天之内连发 0.160.0、0.161.0、0.161.1 三个版本，PyPI 最新版即 0.161.1，这种节奏意味着升级窗口多、但破坏性变更也更值得逐条读 release note。选型层面它的真实收益仍是「一处类型定义，校验/文档/补全三头都受益」这条链路，代价是这层链路完全绑在 Pydantic 的大版本演进上，历史上 Pydantic v1→v2 的迁移成本就曾把不少项目卡在升级半途。
