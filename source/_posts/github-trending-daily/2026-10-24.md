## 1. [NVIDIA/OpenShell](https://github.com/NVIDIA/OpenShell)
- **语言**：Rust
- **总 Star**：18,833
- **当日新增**：+1,119/天
- **简介**：NVIDIA 开源的自主 AI Agent 运行时，官方定位为「给成批（fleet）agent 用的安全、私有运行环境」，主体用 Rust 编写并同时提供 PyPI 包 `openshell`，文档挂在 docs.nvidia.com 下；仓库 2026-02-24 创建，许可证 Apache-2.0，当前有 1,886 个 fork、577 个未关闭 issue，发布节奏为每周版（v0.1.4 于 2026-10-13、v0.1.5 于 2026-10-20）。
- **亮点**：它抢的是「agent 从 demo 走向可长期运行」中间那一层基建：README 把 0.1.x 的新内容明确列为更稳定的发版节奏、新的隔离（isolation）原语、扩大的扩展面和新增 API——也就是把沙箱边界和外挂能力做成运行时职责，而不是让每个 agent 项目自己重复造一遍。需要留意的是它仍在 0.x 且官方专门写了 0.1.0 升级指南，说明 API 还在变动期，接入前应对照 upgrade guide 评估改造量；8 个月攒到 1.8 万 star、当日增量还是全榜第一，可见这条赛道的关注度目前高于其成熟度。

## 4. [OpenBMB/VoxCPM](https://github.com/OpenBMB/VoxCPM)
- **语言**：Python
- **总 Star**：40,282
- **当日新增**：+150/天
- **简介**：面壁智能（OpenBMB）开源的 VoxCPM2 语音合成模型，走 Tokenizer-Free 路线（不先把音频离散成 token 再级联），主打多语言语音生成、创造性音色设计与高保真声音克隆，基于 PyTorch；2025-09-16 创建，Apache-2.0 许可证，4,579 个 fork，官网 voxcpm.com，最新 release 为 2.0.3（2026-05-11，内容为微调校验、运行时稳定性与流式改进）。
