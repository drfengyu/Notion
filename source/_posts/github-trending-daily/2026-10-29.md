## 1. [xiaolai/the-craft-of-selfteaching](https://github.com/xiaolai/the-craft-of-selfteaching)
- **语言**：Jupyter Notebook
- **总 Star**：18,544
- **当日新增**：+148/天
- **简介**：李笑来的开源书《自学是门手艺》，2019-03-14 建仓，整本书以 `.ipynb` 单元的形式发布，README 建议先在本地装好 Jupyterlab 再读，英文副标题写的是 "One has no future if one couldn't teach themself"，中文口号「没有自学能力的人没有未来」。它不是单纯的编程教程，而是把编程当成自学方法的入口：Part.1 先论证为什么必须掌握自学能力、为什么从编程入手、如何「只靠阅读习得新技能」、开始阅读前要做什么准备，随后是 Python 基础七章（值及其运算、流程控制、函数、字符串、数据容器、文件），再加两篇很实用的专章——「如何从容应对含有过多『过早引用』的知识」和本地化的官方 The Python Tutorial；Part.2 讲笨拙与耐心、刻意练习、为什么从函数开始，然后是参数上下、lambda、递归、docstrings、模块化、测试驱动开发、可执行 Python 文件与刻意思考；Part.3 是战胜难点、面向对象两章、装饰器/迭代器/生成器、正则表达式、BNF 与 EBNF、拆解、刚需幻觉、「全面 —— 自学的境界」、自学者的社交、这是自学者的黄金时代（讲 Google 检索力）、避免注意力漂移；末尾另有如何成为优秀沟通者、自学者的终点、下一步干什么，以及四篇附录（VS Code 安装配置、Git 简介、Jupyterlab 安装、符号对照表）。仓库里还专门写了一章「如何证明你真的读过这本书？」，教读者用 Pull Request 给书做校对，README 顶部那段伪代码 `def teach_yourself(anything): while not create(): learn(); practice(); return teach_yourself(another)` 就是全书主张的压缩版。2019-03-23 另增了 Markdown 版本（挂在 selfteaching 组织下）。版权协议为 CC-BY-NC-ND 3.0（署名、非商业性使用、禁止演绎），717 个 watcher、17,890 个 fork，最后一次提交停在 2026-05-20。
- **亮点**：17,890 fork 对 18,545 star，比例接近 1:1，这个数字本身就是这本书最好的说明书——它不是一个「读完顺手 star 一下」的资料仓库，而是一本要求读者 fork 下来改、提交 diff 才算读过的作业本，proof-of-work 那一章把「你读过」直接定义成「你有过校对记录」。对今天的做课程、做内部文档的人，能搬走的是这套结构：把知识切成「可执行的 notebook 单元 + 每章留一个动手任务」，让阅读天然产出可验证的交付物，而不是靠课后问卷。三点使用前的判断：这是个人自出版的书，方法论部分（刻意练习、耐心、注意力）大量转述主流畅销书观点且不带引证，实操部分按今天的标准看偏旧（Python 3.7 时代，工具链与依赖建议多年未跟进），且 2019 年后已停止实质更新；协议上 CC-BY-NC-ND **禁止演绎且禁止商用**，想改写成企业内训教材、翻译后再分发或删减重排都不合规，引用原文必须署名且不得修改；它的位置应该是「自学方法的思维框架 + 一门语言的完整自学路径样本」，而不是 Python 入门教材本身——真要学今天的 Python，得配一本仍在维护的资料并自行替换过时写法。
