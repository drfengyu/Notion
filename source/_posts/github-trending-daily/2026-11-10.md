## 1. [garrytan/gbrain](https://github.com/garrytan/gbrain)
- **语言**：TypeScript
- **总 Star**：32,188
- **当日新增**：+216/天
- **简介**：Garry Tan 本人维护的 OpenClaw/Hermes Agent 大脑，把记忆、技能与工具调度打包成一个可自托管的 agent 运行时。
- **亮点**：最新 release 是 v0.60.633.0，而 `releases.atom` 里从 11-09 23:07 的 v0.60.627.0 到 11-10 01:21 的 v0.60.633.0 只有约两小时、共 7 个版本，密度接近 CI 触发。这一批的核心是新增 `gbrain skills index build|status|remove` 与 `gbrain skills resolve`：一个不依赖推理引擎的技能解析器，用一轮用户输入给宿主 harness 的技能目录排序，最多输出 5 条建议、400 token 的 `<relevant_skills>` 块，专门解决「一个 agent 挂了几百个技能时不知道该看哪几个」；它默认关闭，且 BM25F 排序目前只做词面匹配，也明确写了在无 brain、瘦客户端、以及 `gbrain serve` 持有 PGLite 锁时同样可用。

## 2. [homeassistant-ai/ha-mcp](https://github.com/homeassistant-ai/ha-mcp)
- **语言**：Python
- **总 Star**：6,026
- **当日新增**：+31/天
- **简介**：把 Home Assistant 封装成 MCP 服务，让 Claude、ChatGPT 等 AI 助手直接用自然语言读取和配置智能家居的设备、实体与自动化。
- **亮点**：11-08 刚发 v9.1.2 稳定版并同步更新 `stable` 标签，11-09 一天内就推了 dev3430、dev3434、dev3435、dev3439、dev3444 共 5 个 9.2.0 开发构建——典型的「稳定版刚落地就全力开发下一版」。release 正文同时提醒使用者：能收到这些 dev 构建是因为 HACS 里该仓库的 **Pre-release** 开关处于打开状态，关掉即回到仅稳定版；换句话说这个项目把 CI 产物当作半官方分发渠道，不同订阅方式的人看到的版本线完全不同。
