## 1. [milind-soni/OpenMausBot](https://github.com/milind-soni/OpenMausBot)
- **语言**：TypeScript（Electron + React 19 + Vite + Tailwind，严格类型；曾名 OpenGrokBot，亦称 MausBot）
- **总 Star**：7,532
- **当日新增**：+1,199/天
- **简介**：开源的 Grok Bot 替代品——把个人 agent 做成一款 Telegram 式聊天应用，侧边栏每个「联系人」都是你本机已登录的 `claude` / `codex` / `grok` CLI 跑起来的真实 agent，各自带性格、模型、自己的云电脑与连接的应用，shell 命令和文件改写以 Allow/Deny 卡片就地询问，转录、密钥与事件全部留在本地 `~/.openmausbot` 而不是云端。
- **亮点**：2026-08-11 建仓、两个半月做到 7,532 star / 1,120 fork、91 个 release，最新 0.1.134 就发布在今天 00:40Z（昨天还有 0.1.133、0.1.132），迭代近乎一天两版；更值得看的是它的边界与供应链做法——Ubuntu Wayland 因安全门未解（issue #345）直接 fail-closed 禁用本地控制，Linux 打包只下载 tag 固定的上游归档并校验体积、SHA-256、完整成员白名单与内层可执行文件哈希并随包附 CycloneDX SBOM，对外暴露的 stdio MCP 控制面刻意不含审批授权、删除、凭据与电脑生命周期，`enterprise/` 目录是 source-available 而非 Apache-2.0（生产运行要许可证、白标要伙伴协议，删掉该目录即纯 OSS 版并有 CI 证明），而 README 顶部专门声明与任何加密货币无关、 maintainer 从未收到代币——它已经开始被人蹭名发币。

## 3. [CopilotKit/OpenBot](https://github.com/CopilotKit/OpenBot)
- **语言**：TypeScript（Bun 1.4+ workspace，Hono API + React/Vite + Docker Compose，可切 gVisor `runsc`）
- **总 Star**：8,190
- **当日新增**：+247/天
- **简介**：CopilotKit 放出的「公司可以自己真正拥有」的 AI 同事平台：每个 coworker 拿到一台属于自己的容器电脑（一个 Chromium、自己的登录态与文件），任何浏览器、文件、shell、MCP 或组件调用都必须经过同一个网关——先按服务端持有的快照解析目标、用 CEL 策略判定、写下审计行，然后才执行或拒绝并点名规则，agent 本身来自任意 AG-UI 端点（LangGraph、Mastra、CrewAI、Pydantic AI、Google ADK 或手写）。
- **亮点**：定位要读准——README 明说这是「a template, not a product」，没有托管版、仓库里每个 workspace 都是 private，你 clone 之后把 `examples/` 下的示例租户包换成自己的 coworker 再跑，而它同时是 CopilotKit 的销售入口（通篇「Talk to an engineer / 我们帮你在自家基础设施里落地」，自带求助横幅且付费 Intelligence 计划才消失，模型不自带、必须管理员提供密钥，会话与记忆落在 CopilotKit Intelligence，免费版可本地 Docker 评估但许可 30 天需 `copilotkit local renew`）；策略面做得比多数同类产品硬：deny 先于 allow、缺策略即什么都不能做、规则写坏是拒绝而非放行，`initiator.*` 允许「拒绝定时例程、放行真人」，人类接管期间 bot 动作被拒而非排队，密钥只记录「被请求过及其长度」绝不进转录，默认全部回环绑定加每容器 token。工程现状：2026-08-17 建仓、1,048 fork / 33 watcher、19 个 release，最新 v0.2.0 在 2026-10-12，但最后提交（10-29 20:07Z，#871）里的未发布改动已把「每个 Bot 一台电脑」换成「每人一台 + 按需 Isolated」，附带迁移 `0069_isolated_bots`、公开 bot 需重新登录、浏览器默认改 headed、Helm 电脑内存默认抬到 2Gi request / 8Gi limit——按 changelog 的口径，升级前有十六处会对现有部署行为产生影响。
