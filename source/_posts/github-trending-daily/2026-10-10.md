## 1. [Robbyant/lingbot-map](https://github.com/Robbyant/lingbot-map)
- **语言**：Python
- **总 Star**：17,727
- **当日新增**：+110/天
- **简介**：Robbyant 团队开源的**流式三维重建前馈基础模型** LingBot-Map（ECCV 2026 最佳论文奖候选，已挂出会议版论文与 arXiv 技术报告）。它提出「几何上下文 Transformer」（Geometric Context Transformer），用一个流式框架同时解决三件事：坐标锚定（anchor context）、稠密几何线索注入（pose-reference window）、以及长程漂移校正（trajectory memory）；推理侧采用前馈架构加分页 KV Cache 注意力，在 518×378 分辨率下可稳定跑到约 20 FPS，并支撑超过 10,000 帧的长序列而不崩。权重已在 Hugging Face 与 ModelScope 同步发布，Apache-2.0 许可。
- **亮点**：三维重建这条线过去分成两派——SLAM/BA 类要迭代优化、慢但准，前馈点图类快但长序列会漂。这个工作的价值在于把「漂移校正」做进架构本身（用轨迹记忆和参考窗口当上下文），而不是靠后处理回环，于是首次让「实时前馈」和「长序列不漂」不再互相牺牲；对做空间智能、机器人建图、视频转 3D 资产的人来说，这是一个可以直接接进在线管线的底座，而不只是又一个刷榜论文。

## 2. [BerriAI/litellm](https://github.com/BerriAI/litellm)
- **语言**：Python
- **总 Star**：60,692
- **当日新增**：+95/天
- **简介**：开源 AI 网关，把 100+ 家模型供应商（OpenAI、Anthropic、Gemini、Bedrock、Azure、VertexAI、vLLM、Nvidia NIM 等）统一到 OpenAI 格式的调用接口下。项目近期把核心改写为 **Rust 内核 + Python SDK**，主打「最快最轻的 AI Gateway」；两种用法：作为 Python 库直接集成，或部署为 Proxy Server 给团队集中管理，自带虚拟密钥、花费追踪、Guardrails、负载均衡、日志与管理面板，并提供 Render / Railway / AWS / GCP 一键部署入口。
- **亮点**：它是那种「文档比代码更早成为标准」的项目——多数团队的 LLM 网关选型清单里它就是默认答案。真正值得注意的是这次的重写方向：Python 网关的性能瓶颈在请求编排与鉴权中间层，把它换成 Rust 内核意味着作者承认了这一层的成本，并把「按 token 计费、跨供应商故障切换」这类高频路径下推到系统层。如果你已经在用它，这次升级属于值得回归测试的版本（自托管 Proxy 的策略与密钥格式需要重点验证）。

## 3. [twostraws/SwiftUI-Agent-Skill](https://github.com/twostraws/SwiftUI-Agent-Skill)
- **语言**：Markdown / YAML（Agent Skill，非可编译代码库）
- **总 Star**：5,464
- **当日新增**：+65/天
- **简介**：《SwiftUI 入门》作者 Paul Hudson（twostraws）整理的 SwiftUI **Agent Skill 包**，面向 Claude Code、Codex、Gemini、Cursor、Xcode 等 AI 编码助手：把「现代 SwiftUI 该怎么写」写成可被模型加载的技能，覆盖导航、布局、动画、状态管理、VoiceOver 无障碍与已废弃 API，明确针对「LLM 真正会犯的那些错」。走 [Agent Skills](https://agentskills.io/home) 格式，一行 `npx skills add` 即可安装，也可通过 Claude Code 插件市场装；同一作者还有 SwiftData Pro、Swift Concurrency Pro、Swift Testing Pro 等姊妹技能。MIT 许可。
- **亮点**：这是「专家经验被产品化」的一个清晰样本——它卖的不是代码而是纠偏规则：模型写 SwiftUI 的常见病（用旧的 `NavigationView`、状态提升放错层、动画绑值不对、忽略无障碍标签）恰好是文档里最难靠语料自动学会的部分，由长期写书和做教学的人来定规约，收益直接可见。对 Apple 平台团队的现实启发是：与其在每个 AGENTS.md 里临时补提示，不如把这类技能当作可版本化、可评审的团队依赖来管理。
